# LogicMonitor Text widget

## Paste this file into LogicMonitor

**[`Better_Map_Widget-CDN.html`](Better_Map_Widget-CDN.html)**

1. Open that file in GitHub or in Cursor.
2. Select all and copy.
3. In LogicMonitor: Text widget → **Source** → paste → **Save**.

This small loader pulls the full widget from GitHub (`src/Better_Map_Widget.js`, CSS, icons, and data). You do not paste those files separately.

After any GitHub update, copy and re-paste this file again, then hard-refresh the dashboard.
