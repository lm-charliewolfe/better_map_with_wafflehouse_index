# Widget assets (CDN)

These files are **loaded automatically** from GitHub when the dashboard runs the CDN loader.

**Do not paste these into LogicMonitor.** Paste only:

[`../logicmonitor/Better_Map_Widget-CDN.html`](../logicmonitor/Better_Map_Widget-CDN.html)

| Path | Purpose |
|------|---------|
| `Better_Map_Widget.js` | Map widget logic + Waffle House overlay |
| `Better_Map_Widget.css` | Styles |
| `icons/` | Map marker images |
| `data/wafflehouse.json` | Waffle House location data |

The CDN loader pins a git commit and loads these paths from jsDelivr / GitHub raw.
